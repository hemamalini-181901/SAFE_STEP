# 🛡️ SafeStep – Smart Maternal Safety & Monitoring System

MAIN : https://exquisite-jelly-7bee07.netlify.app

**Because Every Step Matters.**

SafeStep is a smart maternal safety platform designed to support the safety and well-being of pregnant women through intelligent technology, connected systems, and voice-based assistance.

The platform provides a simple homepage through which users can access two major modules: **Agent** and **Voice Assistant**.

## 🌟 Key Features

### 1. Agent
- Provides access to the SafeStep Agent interface.
- Connects users to the intelligent device management platform.
- Designed to support interaction with the SafeStep monitoring system.

🔗 **Explore Agent:**  
https://lustrous-sundae-98fd22.netlify.app

### 2. Voice Assistant
- Supports voice-based interaction.
- Records conversations and converts speech into text.
- Generates intelligent conversation insights and reports.

🔗 **Open Voice Assistant:**  
https://hemamalini-181901.github.io/ConvoLens-AI/

## 🚀 How to Run Locally

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder in Visual Studio Code.

3. Make sure all three files are present:
   - `index.html`
   - `style.css`
   - `app.js`

4. Install the **Live Server** extension in VS Code.

5. Right-click `index.html`.

6. Select **Open with Live Server**.

7. Your SafeStep homepage will open in your browser.
